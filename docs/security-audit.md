## 低危发现（已缓解/可接受）

### 1. TTS 缓存键使用 MD5 🟢

**位置**: `media.py:59`

```python
key = hashlib.md5(f"{text}_{voice}_{speed}".encode()).hexdigest()
```

**风险**: MD5 不是加密哈希，理论上存在碰撞可能。

**缓解**: 缓存文件只存储 TTS 音频，不含敏感信息；碰撞最多导致音频错乱，无安全影响。

**建议**: 可改用 SHA-256，但优先级低。

### 2. 异常信息可能包含内部路径 🟢

**位置**: `main.py:123-126` 等日志输出

**风险**: 日志中可能包含文件路径。

**缓解**: 日志文件位于用户本地目录（`%LOCALAPPDATA%/IELTSInsight/logs/`），不上传、不共享。

**建议**: 如需进一步降低风险，可在日志中混淆路径。

### 3. 无速率限制 🟢

**位置**: 所有 API 端点

**风险**: 理论上可被暴力调用。

**缓解**: 应用绑定 `127.0.0.1`（仅本机访问），不暴露公网。

**建议**: 如需网络访问，应添加速率限制。

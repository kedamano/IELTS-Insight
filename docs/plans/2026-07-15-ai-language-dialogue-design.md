## 1. 产品定位

AI 英语学习桌面应用，专注**听说闭环**。用户打开应用后，从预设场景库中选择场景（如餐厅点餐、机场问路、工作面试、商场购物等），每个场景提供一段标准英语对话示范。

**核心体验：** 先完整听一遍对话，再逐句跟读。用户点击"跟读"按钮，系统通过麦克风录音，将用户发音转写为文字，与原文对比后给出三维评分：发音准确度（0-100）、流利度、完整度。发音问题高亮标注，AI 给出口型/舌位改进建议。

- **目标人群**：大学生、职场人士、英语自学者
- **语言**：专注中英双语，界面全中文，降低学习门槛
- **隐私**：所有语音处理本地完成，无需联网，保护隐私
- **桌面端**：Tauri 2.x 轻量壳，Windows/macOS 双端，启动快、内存低

### 商业模式

| 分级 | 场景数 | 内容 | 价格 |
|------|--------|------|------|
| 🆓 免费 | 5 个 | 点餐、问路、购物、自我介绍、打电话 | 免费 |
| 💎 Pro | 15+ | 面试、商务谈判、就医、银行、租房、旅行、学术讨论等 | ¥19 解锁全部 |

## 2. 架构与数据流

### 2.1 技术栈

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| **桌面壳** | Tauri 2.x | Rust + WebView2，启动快、体积小（~80MB）、原生体验 |
| **前端** | React 19 + TypeScript + Vite + TailwindCSS | 现代 React，TypeScript 安全，Vite 极速 HMR |
| **UI 组件** | shadcn/ui | 极简、非封装、与 Tailwind 无缝配合 |
| **后端** | Python + FastAPI | 异步高性能，生态完善 |
| **TTS** | edge-tts | 微软 Edge TTS，免费，音质出色，支持美式/英式切换 |
| **STT** | OpenAI Whisper | 本地运行，英文识别字准 95%+，中文 90%+ |
| **AI 评分** | OpenAI GPT / 本地 LLM | Prompt 工程驱动发音纠错 |
| **数据库** | SQLite | 轻量本地存储，零配置 |
| **音频处理** | FFmpeg + RNNoise | 格式转换 + 轻量降噪 |

## 5. 评分模型（核心算法）

### 5.1 三维评分权重

| 维度 | 权重 | 计算方法 |
|------|------|----------|
| **发音准确度** | 50% | 音素级对比（PhoneticLevenshtein），对比用户发音与标准发音的音素序列差异，映射到 0-100 |
| **流利度** | 30% | WPM（Words Per Minute）对比 + 停顿检测；目标语速 150 WPM，偏离越大扣分越多 |
| **完整度** | 20% | WER（Word Error Rate）：`(S+D+I) / N × 100%`，转写文本与原文的词错率 |

### 5.2 AI 纠错 Prompt

```
【角色定义】
你是一位资深英语口语教练，擅长通过对比分析学习者的发音问题。

【输入信息】
原文：How are you doing today?
用户转写：[Whať a'yü dü-ing t'dei?]

【分析要求】
1. 逐词发音对比，标注发音音素差异
2. 问题分类（从以下选择）：
   - 辅音错误（如 /θ/ 读成 /s/）
   - 元音错误（如 /æ/ 读成 /ɛ/）
   - 连读问题
   - 弱读缺失
   - 重音错误
   - 语调问题
3. 给出口型/舌位/气流的具体改进建议
4. 用中文回答，语气鼓励，不超过 150 字

【输出格式】（严格 JSON）
{
  "word_scores": [
    {"word": "How", "score": 85, "error_type": "辅音错误", "tip": "/aʊ/ 开口度要够大"},
    {"word": "are", "score": 95, "error_type": null, "tip": null}
  ],
  "overall_tip": "整体语调上扬自然，注意 'are' 的弱读形式 /ə/"
}
```

### 5.3 错题管理机制

- 自动归档：每次评分后，音素错误自动记录
- 分类统计：按音素类型分组（/θ/、/æ/、/l/、/r/、/ɪ/ 等中国学生高频错误）
- 掌握标准：同一音素连续 3 次 80+ 分 → 从错题本移除
- 定期复习：累计 5 条错题时推送"错题回顾"练习

## 6. 错误处理与容错

### 6.1 语音处理异常

| 场景 | 检测方式 | 处理策略 |
|------|----------|----------|
| 麦克风权限拒绝 | MediaDevices 抛错 | 弹窗引导开启权限（附带系统设置跳转） |
| 环境噪音过大 | 实时 SNR 检测（阈值 20dB） | 提示"请在安静环境练习"，阻止录音 |
| Whisper 转写超时 | 后端 15s 超时 | 返回超时错误，前端提示"录音时间过长" |
| 网络不可用 | navigator.onLine | 检测提示联网下载模型（≈150MB），支持断点续传 |
| edge-tts 限流 | 429 响应 | 自动重试（最多 3 次），本地缓存避免重复请求 |
| GPT 评分限流 | 429 / 503 | 降级为本机规则评分（仅 WER 对比） |

### 6.2 音频处理链路

```
麦克风录音 → MediaRecorder (WebM, 48kHz)
    │
    ▼
前端端点检测（VAD Silence，停顿 > 300ms 自动截断）
    │
    ▼
发送至 FastAPI 后端 → FFmpeg 转 16kHz WAV
    │
    ▼
RNNoise 降噪（可关闭）→ 保存至内存
    │
    ▼
Whisper 转写 → 获取文本 + 时间戳
    │
    ▼
GPT 评分 Prompt → 获取纠错建议 + 三维分数
    │
    ▼
返回前端展示
```

### 6.3 桌面端特有容错

- 模型文件损坏 → 下载前校验 SHA256，损坏后提示重下
- 磁盘空间不足 → 低于 500MB 时清理 7 天前的音频缓存
- 系统唤醒恢复 → 暂停录音，避免录入唤醒杂音

### 6.4 离线降级策略

| 离线可用 | 离线不可用 |
|----------|----------|
| Whisper 本地转写 | edge-tts（需联网） |
| SQLite 数据读写 | GPT 评分（降级为本机规则评分） |
| 历史练习记录查看 | Pro 场景内容下载（首次需联网） |

## 附录 B：第三方服务选型

| 需求 | 选型 | 备选 | 理由 |
|------|------|------|------|
| TTS | edge-tts | pyttsx3 / gTTS | 免费、音质高、支持美/英音切换 |

| 桌面壳 | Tauri 2.x | Electron | 体积小 10 倍、启动快、内存低 |
| 数据库 | SQLite | Realm / lowdb | 零配置、轻量、单文件 |

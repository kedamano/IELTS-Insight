## 1. 产品定位

AI 英语学习桌面应用，专注**听说闭环**。用户打开应用后，从预设场景库中选择场景（如餐厅点餐、机场问路、工作面试、商场购物等），每个场景提供一段标准英语对话示范。

**核心体验：** 先完整听一遍对话，再逐句跟读。用户点击"跟读"按钮，系统通过麦克风录音，将用户发音转写为文字，与原文对比后给出三维评分：发音准确度（0-100）、流利度、完整度。发音问题高亮标注，AI 给出口型/舌位改进建议。

- **目标人群**：大学生、职场人士、英语自学者
- **语言**：专注中英双语，界面全中文，降低学习门槛
- **隐私**：默认语音处理本地完成，联网时可选 AI 深度点评，可在设置中完全关闭联网功能
- **桌面端**：Tauri 2.x 轻量壳，Windows/macOS 双端，启动快、内存低

### 商业模式

| 分级 | 场景数 | 内容 | 价格 |
|------|--------|------|------|
| 🆓 免费 | 5 个 | 点餐、问路、购物、自我介绍、打电话 | 免费 |
| 💎 Pro | 15+ | 面试、商务谈判、就医、银行、租房、旅行、学术讨论等 | ¥19 解锁全部 |

## 2. 产品核心原则

> 本章定义产品设计的基本原则，所有功能开发需遵循这些原则。

### 2.1 极简学习流程

**核心理念**：用户打开应用后，应在 **30 秒内**开始第一次跟读，无需复杂设置，避免学习成本过高。

| 原则 | 说明 |
|------|------|
| **零配置启动** | 首次启动后，引导流程不超过 4 步，直接进入第一个免费场景 |
| **一键跟读** | 每个句子只需点击一次"跟读"按钮，无需额外操作 |
| **即时反馈** | 录音结束后 3 秒内展示评分，无需等待 |
| **渐进式引导** | 高级功能（Shadowing、AI 解析）默认隐藏，用户主动探索时展示 |

### 2.2 听说闭环

每个场景均遵循固定学习流程，形成完整闭环：

```
听示范 → 理解内容 → 逐句跟读 → AI评分 → 查看纠错 → 重新练习 → 记录学习成果
```

| 环节 | 用户行为 | 系统反馈 |
|------|----------|----------|
| **听示范** | 点击"播放示范" | 逐句高亮 + TTS 播报，可点击单句重播 |
| **理解内容** | 阅读双语对照 | 英文 + 中文翻译 + 关键词提示 |
| **逐句跟读** | 点击"跟读"按钮 | 录音最长 30s，自动端点检测 |
| **AI评分** | 等待评分 | 三维分数 + 逐词热力图 + AI 纠错 |
| **查看纠错** | 点击问题词汇 | 显示音素对比、口型建议、文化说明 |
| **重新练习** | 点击"重录" | 覆盖上次记录，保留最佳成绩 |
| **记录成果** | 完成所有句子 | 自动归档至学习报告 + 错题本 |

### 2.3 鼓励式学习

**核心理念**：评分不仅用于指出错误，更强调鼓励用户持续练习。

#### 2.3.1 鼓励式话术规范

| 场景 | ❌ 避免 | ✅ 推荐 |
|------|--------|--------|
| 发音较好 | "发音错误较多" | "你的发音已经非常自然，仅需注意 /θ/ 的舌尖位置" |
| 流利度低 | "语速太慢，不流利" | "语速稳定，尝试加快到 150 WPM 会更自然" |
| 完整度低 | "漏读了 3 个词" | "核心词汇都读对了，注意 'a'、'the' 等小词不要漏掉" |
| 高分鼓励 | "分数：95" | "太棒了！95 分，发音接近母语者水平" |

#### 2.3.2 正向反馈机制

- **即时鼓励**：评分 80+ 时，界面显示 🎉 动画 + 鼓励文案
- **连续打卡**：每日练习后显示"连续学习 X 天"，中断后温和提醒而非惩罚
- **进步可视化**：学习报告展示"比上周进步 +5 分"，而非仅显示绝对分数
- **成就解锁**：达成特定目标时弹出成就徽章（见第 6 章）

## 3. 架构与数据流

### 3.1 技术栈

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| **桌面壳** | Tauri 2.x | Rust + WebView2，启动快、体积小（~80MB）、原生体验 |
| **前端** | React 19 + TypeScript + Vite + TailwindCSS | 现代 React，TypeScript 安全，Vite 极速 HMR |
| **UI 组件** | shadcn/ui | 极简、非封装、与 Tailwind 无缝配合 |
| **后端** | Python + FastAPI | 异步高性能，生态完善 |
| **TTS** | edge-tts（优先）→ Windows SAPI / macOS say / Linux espeak（降级）| 微软 Edge TTS 免费音质高；离线时降级为系统 TTS |
| **STT** | OpenAI Whisper | 本地运行，英文识别字准 95%+，中文 90%+ |
| **AI 评分** | 规则评分（本地）+ GPT 深度点评（联网可选）| 默认本地规则评分，联网时启用 AI 增强 |
| **数据库** | SQLite | 轻量本地存储，零配置 |
| **音频处理** | FFmpeg + RNNoise | 格式转换 + 轻量降噪 |

## 8. 评分模型（核心算法）

### 8.1 三维评分权重

| 维度 | 权重 | 计算方法 |
|------|------|----------|
| **发音准确度** | 50% | 音素级对比（Phonetic Levenshtein），对比用户发音与标准发音的音素序列差异，映射到 0-100 |
| **流利度** | 30% | WPM（Words Per Minute）对比 + 停顿检测；目标语速 150 WPM，偏离越大扣分越多 |
| **完整度** | 20% | WER（Word Error Rate）：`(S+D+I) / N × 100%`，转写文本与原文的词错率 |

### 8.2 发音评分流程（核心）

```
用户录音
    │
    ▼
Whisper 语音转写
（获得文本 + 时间戳）
    │
    ▼
Forced Alignment 音素对齐
（Montreal Forced Alignment / Gentle）
    │
    ▼
提取用户音素序列 + 时间信息
    │
    ▼
音素比对
（与标准音素序列计算 Levenshtein 距离）
    │
    ▼
准确率评分
（音素正确率 × 100）
    │
    ▼
LLM 生成中文建议
（联网可选，离线时使用预设模板）
```

**重要说明**：Whisper 主要负责**语音识别**（语音 → 文字），不直接承担发音准确度评分。发音准确度由 **Forced Alignment + 音素比对** 完成，评分依据更科学。

### 8.3 本地规则评分（默认）

| 评分项 | 计算方式 |
|--------|----------|
| **音素准确率** | 正确音素数 / 总音素数 × 100 |
| **WPM 得分** | `100 - |用户WPM - 150| / 1.5`，最低 0 分 |
| **停顿得分** | 停顿次数 ≤ 3 得 100，每多 1 次扣 10 分 |
| **WER 得分** | `(1 - WER) × 100` |

### 8.5 错题管理机制

- **自动归档**：每次评分后，音素错误自动记录

## 9. Shadowing 模式（V1.5）

### 9.1 模式说明

**Shadowing（影子跟读）** 是一种高级口语训练方法，用户需要**立即复述**听到的内容，而不是等一句话结束再跟读。

| 对比项 | 普通模式 | Shadowing 模式 |
|--------|----------|----------------|
| **播放方式** | 完整播放一句 | 连续播放整段对话 |
| **跟读时机** | 播放结束后跟读 | 听到后立即复述（延迟 0.5s） |
| **训练目标** | 单句发音准确度 | 节奏、连读、语调、反应速度 |
| **难度** | ⭐⭐ | ⭐⭐⭐⭐ |
| **适用人群** | 初学者 | 进阶学习者 |

### 9.2 适用训练

| 训练目标 | 说明 |
|----------|------|
| **节奏** | 适应英语的自然节奏，避免"一字一顿" |
| **连读** | 掌握连读规则（如 "How many-people"） |
| **语调** | 模仿升调/降调，表达情感和意图 |
| **反应速度** | 提升听力到口语的转换速度 |

### 9.3 设置切换

在设置页面中提供模式切换：

| 设置项 | 选项 |
|--------|------|
| **练习模式** | 普通模式 / Shadowing 模式 |
| **Shadowing 延迟** | 0.3s / 0.5s / 0.7s（默认 0.5s） |
| **播放速度** | 0.75x / 1.0x / 1.25x |

## 13. 错误处理与容错

### 13.1 语音处理异常

| 场景 | 检测方式 | 处理策略 |
|------|----------|----------|
| 麦克风权限拒绝 | MediaDevices 抛错 | 弹窗引导开启权限（附带系统设置跳转） |
| 环境噪音过大 | 实时 SNR 检测（阈值 20dB） | 提示"请在安静环境练习"，阻止录音 |
| Whisper 转写超时 | 后端 15s 超时 | 返回超时错误，前端提示"录音时间过长" |
| 网络不可用 | navigator.onLine | 自动切换离线模式，禁用联网功能 |
| edge-tts 限流 | 429 响应 | 自动重试（最多 3 次），本地缓存避免重复请求 |
| edge-tts 不可用 | 网络错误 | 降级为系统 TTS（Windows SAPI / macOS say / Linux espeak） |
| GPT 评分限流 | 429 / 503 | 降级为本机规则评分 |

### 13.2 音频处理链路

```
麦克风录音 → MediaRecorder (WebM, 48kHz)
    │
    ▼
前端端点检测（VAD Silence，停顿 > 300ms 自动截断）
    │
    ▼
发送至 FastAPI 后端 → FFmpeg 转 16kHz WAV
    │
    ▼
RNNoise 降噪（可关闭）→ 保存至内存
    │
    ▼
Whisper 转写 → 获取文本 + 时间戳
    │
    ▼
Forced Alignment 音素对齐 → 获取音素序列
    │
    ▼
本地规则评分 → 三维分数 + 逐词热力图
    │
    ▼
（联网可选）GPT 深度点评 → 详细纠错建议
    │
    ▼
返回前端展示
```

### 13.3 离线策略（修订版）

**核心原则**：默认情况下，语音识别、学习记录和基础评分均在本地完成。联网时可启用 AI 深度点评，提供更详细的发音分析、口型建议及文化表达说明。用户可在设置中完全关闭联网功能。
